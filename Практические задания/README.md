# Практические задания

Карточки заданий курса **«Программирование на Java для тестировщиков»** — по одной на встречу. Домашних заданий нет: всё выполняется на занятиях. Заглядывать вперёд можно, но код пишем вместе на встрече.

Карточка итогового практикума (встреча 10) выдаётся в день финала.

Работайте в этом проекте. Код, который на занятии выдаётся готовым, лежит в `заготовки/NN` (модули 2, 3, 4, 7). Опора по синтаксису — `Памятка участника — опоры Java.md` в корне проекта.

## Формат карточки

- `База` — обязательная часть для всех.
- `Практика+` — для тех, кто закончил основную часть раньше группы.
- `Challenge` — усложнение для сильных участников.

«Сценарий» в карточках — отдельный вход с ожидаемым результатом (6 сценариев SLA — 6 тестов). Число запусков и число методов — разные вещи: параметризованный метод с пятью строками — один метод и пять запусков.

## Команды Gradle после модуля 8

| Команда | Что запускает |
|---|---|
| `./gradlew test` | все тесты, кроме UI (`ui`) |
| `./gradlew fastTest` | без медленных (`slow`) и UI |
| `./gradlew smokeTest` | тег `smoke`, без UI |
| `./gradlew regressionTest` | тег `regression` |
| `./gradlew dbTest` | тег `db` |
| `./gradlew apiTest` | тег `api` (HTTP против стаба) |
| `./gradlew uiTest` | тег `ui` (Playwright), отдельной командой |

После каждого изменения тегов проверяйте, что задача запустила не ноль тестов: задача с опечаткой в теге проходит «зелёной» пустой.
